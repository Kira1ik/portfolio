Web Development · Personal Project

Kodebua

Kodebua is a digital platform designed to make programming help more accessible to young developers. The concept connects beginners with people who can help them solve coding problems, understand difficult topics and improve their programming skills.

I developed the website using HTML, CSS and JavaScript, created the visual prototype in Figma and implemented interactive features such as a chatbot, helper filtering, service selection and a booking interface.

02
Game Development · Python

Nordlysjeger

Nordlysjeger is an original arcade-style game inspired by the Northern Lights. The player collects glowing particles while avoiding falling ice crystals. The game includes a scoring system, lives, increasing difficulty and special power-ups.

I developed the game in Python using Pygame, working with game mechanics, collision detection, movement, visual effects and interactive elements. The project helped me explore how programming logic can be used to create a complete interactive experience.

I designed and developed my own website for the project, including information sections, podcast content, interactive quizzes, fact cards and source references. Web Development · Event Website

Badminton Break

Badminton Break is an event website created to present a school badminton event in a clear and engaging way. The website provides essential information about the event, including the schedule, location, participation and activities.

I worked on the visual concept in Figma and developed the website using HTML and CSS. The project focused on responsive design, clear navigation and creating a consistent visual identity for a real school event.
