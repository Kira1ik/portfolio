# Zhanna Sliepnova — Portfolio

Многостраничная версия портфолио. Оригинальные тексты, оформление и изображения сохранены; код разложен по файлам.

## Структура
- `index.html` — главная
- `about.html` — обо мне
- `skills.html` — навыки
- `projects.html` — проекты
- `ambitions.html` — амбиции
- `application.html` — заявка и CV
- `css/style.css` — стили
- `js/images.js` — подключение локальных изображений
- `js/app.js` — интерактивность и переключение языка
- `images/` — изображения

## Запуск
Можно открыть `index.html` напрямую. Для локального сервера из этой папки запусти:

```bash
python -m http.server 8000
```

Затем открой `http://localhost:8000`.
